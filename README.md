SmartCart Customer Segmentation

Project Overview

This project uses Unsupervised Machine Learning to segment customers based on their income, spending patterns, and purchasing behaviour.

Objective

To identify distinct customer groups using K-Means Clustering and understand their purchasing behaviour for targeted marketing strategies.

Dataset

The dataset contains customer demographics, income, product spending, and purchasing information.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

Machine Learning Algorithm

- K-Means Clustering

Project Workflow

1. Data Loading
2. Data Understanding
3. Data Cleaning
4. Exploratory Data Analysis (EDA)
5. Feature Engineering
6. Feature Scaling
7. Optimal Cluster Selection using Elbow Method
8. K-Means Clustering
9. Customer Segment Analysis
10. Visualization and Insights

Features Used

- Income
- Total Spending
- Total Purchases

Results

Customers were divided into 4 clusters based on income, spending, and purchasing behaviour.

Conclusion

Customer segmentation helps businesses identify different customer groups and develop personalized marketing strategies, improve customer engagement, and make better business decisions.
